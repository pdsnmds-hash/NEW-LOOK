# NEW LOOK — reference kit

Это пакет задания и дизайн-референсов для агента, не исходный Android-проект и не APK.

## Как использовать

1. Распакуйте ZIP и передайте агенту всю папку.
2. Попросите: «Прочитай 01_AGENT_PROMPT_RU.md и реализуй приложение с учётом всех файлов пакета».
3. Откройте design-reference.html в браузере: шесть экранов, обе темы переключаются верхней кнопкой. Интернет и установка не нужны.
4. Проверяйте готовую реализацию по 04_ACCEPTANCE.md.

## Состав

- 01_AGENT_PROMPT_RU.md — полное задание и последовательность реализации.
- 02_DATA_MODEL.md — сущности, связи, ограничения.
- 03_SCREEN_MAP.md — экраны, действия и состояния.
- 04_ACCEPTANCE.md — 30 критериев приёмки и стратегия проверки.
- 05_IMAGE_PLAN.csv — 19 индивидуальных промптов будущих фотографий; изображения не сгенерированы.
- 06_DESIGN_TOKENS.json — палитры и размеры.
- design-reference.html — адаптивный статический дизайн-референс; работает только переключение тем.

## Принятые решения

NEW LOOK 1 LTD EOOD, BG по умолчанию, EN по выбору. Локальный однопользовательский органайзер без облачной синхронизации и командных доступов. Контакты использованы из сообщения заказчика. Пользовательские данные не отправляются компании. Архив описывает целевую полноценную версию; этапы не исключают обязательные функции.
