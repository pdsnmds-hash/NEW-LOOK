# Карта экранов

| Экран | Основные действия | Состояния |
|---|---|---|
| Onboarding | пропуск, пустое пространство, демонабор | без разрешений до действия |
| Today | открыть/выполнить задачу, быстрый ввод, событие | пусто, просрочено, всё выполнено |
| Tasks | поиск, фильтры, сортировка, multiselect | нет задач, нет результатов, ошибка записи |
| Task editor | сохранить, подзадачи, повторение, reminder | новый, изменённый, ошибка даты, permission denied |
| Project list | создать, архив, поиск | пусто, активные, архив |
| Project detail | list/Kanban, заметки, события | 0 задач, прогресс, архив |
| Calendar | месяц, день, повестка, создать | пустой день, смена месяца/зоны |
| Event editor | даты, место, reminder, .ics | all-day, через полночь, неверный диапазон |
| Notes | поиск, создать, закрепить | пусто, автосохранение, длинный текст |
| Templates | предпросмотр, применить | built-in/user, выбор даты, успех |
| Company home | услуги, о компании, контакт | полностью офлайн |
| Service detail | задачи услуги, шаблоны, избранное | выбранное/невыбранное |
| Service finder | ответы, назад, рекомендации | нет точного совпадения |
| Guide / article | поиск, чтение, template CTA | длинная статья, избранное |
| Favorites | вкладки услуг/статей/шаблонов | пусто, удалённый пользовательский шаблон |
| Contacts | dial, email, map, copy | нет обработчика intent |
| Backup | экспорт, импорт, предпросмотр | отмена SAF, повреждение, подтверждение замены |
| Settings | BG/EN, theme, notifications, reset | отказ разрешения, большой шрифт |

## Правила UX

Системный Back закрывает sheet/editor, затем возвращает в предыдущий экран. На корневых вкладках нет бесконечной истории переключений. После запуска из уведомления Back ведёт в приложение предсказуемо. FAB и нижняя панель не перекрывают последнюю строку. Ошибка сохранения не закрывает редактор и не теряет ввод. Snackbar Undo доступен TalkBack. Завершение задачи видно сразу и сохраняется в БД. Счётчики не подставляются вручную.
