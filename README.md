# NEW LOOK — Android

Нативное приложение по пакету `reference/`: корпоративная визитка NEW LOOK 1 LTD EOOD и локальный однопользовательский органайзер. Kotlin, Compose, Material 3, Room, DataStore, Navigation Compose, WorkManager, AlarmManager. Android 8.0+ (minSdk 26), compile SDK 37 / target SDK 36.

## Версия 1.1 — аудит и переработка интерфейса

Визуальная система переработана: локальный Manrope с болгарской кириллицей, новая шкала текста, спокойные light/dark палитры, тональные карточки, компактная плавающая навигация. Today показывает неделю, настоящий прогресс и карточки проектов; быстрый ввод задач находится внутри проекта; список задач использует LazyColumn, фильтры и массовые действия вынесены в bottom sheet. В календаре раздельные маркеры задач/событий и контекстное создание на выбранную дату. Корпоративная часть получила редакционную фотообложку, компактные услуги и структурированные статьи. More, библиотека шаблонов и настройки переработаны.

Исправлены потеря проекта при массовом переносе срока, бездействующий checkbox поиска, обработка сроков с временем, гонка удаления/автосохранения заметки. Date/time picker заменили необходимость ручного ISO-ввода. Применённый шаблон можно сразу открыть как проект. Экспорт пишет снимок в cache-файл до системного диалога, не помещая весь backup в saved instance state. Добавлен экран ошибки и повторной попытки загрузки. Нажатие активной вкладки из дочернего экрана возвращает к её корню.

Полный аудит: `validation/redesign/AUDIT.md`; итоговый отчёт: `validation/redesign/RESULTS.md`. Снимки до/после находятся в `validation/redesign/before/` и `validation/redesign/after/`.

## Обновления рабочих сценариев

В каждом проекте отдельная история завершённых задач с восстановлением. На доске три этапа одновременно видны на телефоне; меню ⋯ перемещает задачи, а Done открывает историю. Вкладка календаря начинается с двух крупных кнопок: Schedule a meeting и My meetings. Первая открывает выбор даты и редактор новой встречи, вторая — календарь с отмеченными датами существующих встреч и повесткой выбранного дня. Известные демозаписи локализуются по BG/EN без перевода пользовательских записей. Кнопка Back закреплена на странице проекта, нижние вкладки переходят к своим корням.

## Открытие и сборка

Откройте текущую папку в Android Studio. Требуются JDK 17+, Android SDK 37 и разрешённая загрузка Gradle/Maven либо заполненный кэш.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

Стандартный APK: `app/build/outputs/apk/debug/app-debug.apk`. На этой машине SDK находится по пути из локального, не переносимого `local.properties`; на другой машине Android Studio создаст собственный файл. Gradle wrapper включён. Использованы AGP 9.4.1, Gradle 9.6.1, Kotlin/Compose compiler 2.4.21, KSP 2.3.12, Compose BOM 2026.09.00, Room 2.8.5.

Воспроизводимые проверки без сервиса Gradle (используют уже существующий локальный Maven-кэш `.gradle-local`, пути SDK/JDK этой машины):

```sh
python3 tools/verify_room.py
python3 tools/verify_schema.py
python3 tools/verify_offline.py
python3 tools/resolve_cached.py
python3 tools/build_sdk.py
```

`verify_offline.py` проверяет типизацию Kotlin/Compose и выполняет JUnit. Проверка исходников использует вспомогательные R-символы; реальный APK собирается `build_sdk.py` с ресурсами AAPT2. `verify_room.py` запускает настоящий Room KSP, генерирует DAO и схему. Резолвер SDK использует BOM и совместимые доступные версии зависимостей из кэша; фактический список находится в `validation/resolved-artifacts.json`. Официальный Gradle-процесс остаётся основным способом дальнейшей разработки и выпуска.

## Возможности

- Первый запуск на болгарском, выбор BG/EN; светлая, тёмная и системная темы. Обозначенный демонабор загружается только явно и удаляется отдельно.
- Задачи: быстрый ввод, редактор, статусы, приоритеты, сроки, теги, подзадачи с редактированием и порядком, дублирование, удаление с Undo. Фильтры AND между группами/OR внутри, сохранённые фильтры и сортировка, массовые операции, экспорт выбранных задач.
- Проекты: описание, дата, цвет, вычисляемый прогресс, список/Kanban, обратимый архив, привязанные заметки и события. При удалении можно сохранить и отвязать содержимое.
- Повторения: ежедневные, выбранные дни недели, месячные, интервал, окончание по дате/числу; отдельная серия и экземпляры, исключённые даты, устойчивый уникальный ключ, выбор одного/будущих экземпляров.
- Календарь месяца и повестка выбранного дня; события через полночь и на весь день, локальные даты и абсолютные моменты, экспорт ICS.
- Локальные приблизительные напоминания, действия уведомления, отсрочка 10 минут/час/выбранное время, восстановление после перезагрузки и смены времени. Точные будильники не запрашиваются; Android может задержать уведомление.
- Заметки с отложенным автосохранением и flush при выходе/остановке, закрепление и поиск. Общий локальный поиск по рабочим записям, услугам и статьям.
- 8 встроенных двуязычных шаблонов, независимые проекты при применении; собственные шаблоны из проекта с редактированием шагов.
- 5 услуг, подбор с объяснением, About, 4 раскрываемых этапа, 8 практических статей, избранное, реальные phone/email/map/copy действия. Обращение открывает редактируемый текст в почтовом приложении пользователя.
- JSON backup с ID/связями/сериями; предварительная валидация до транзакции, лимит 10 MB/20 000 сущностей, предпросмотр и подтверждение замены, предложение сохранить текущую копию. CSV UTF-8 с quoting и защитой от формул. Файлы через Storage Access Framework.

## Архитектура

`data/Database.kt` — Room-сущности и DAO; `data/Repository.kt` — транзакции и реактивное рабочее пространство, генерация серий и импорт; `data/Reminders.kt` — сверка расписания, receivers и периодическое обслуживание. `domain/Rules.kt` — сроки, повторения, фильтры, CSV/ICS, подбор и валидация; Clock передаётся в логику сроков. `domain/Content.kt` — встроенный контент со стабильными ID. `ui/` — темы, навигация, рабочие и корпоративные экраны, редакторы. ViewModel обрабатывает фоновые операции и ошибки. Room — источник пользовательских данных; UI подписан на Flow. Подзадачи и шаги пользовательского шаблона хранятся структурированным JSON внутри родителя; порядок сохраняется.

Рабочие записи не переводятся при смене языка. Удалённый экземпляр серии сохраняется как исключение; Undo снимает исключение. Срок без времени хранится как LocalDate-строка, не UTC-полночь. Прошедшие экземпляры сохраняются, уведомление серии планируется только для ближайшего актуального. Расписание согласуется с БД при запуске и фоновом обслуживании.

## Проверки и ограничения

Актуальные результаты: `validation/redesign/RESULTS.md`. Основная команда: `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug`. Room migration, уникальность экземпляров, FK, создание/завершение задачи, быстрый ввод, сохранение проекта при переносе срока и независимое применение шаблонов проверяются инструментально.

Проверка на эмуляторе не заменяет полный прогон физического устройства: reboot и OEM-доставка уведомлений, TalkBack, SAF roundtrip и весь исходный список приёмки остаются отдельными выпускными проверками. JSON-копии не зашифрованы. При hardware GPU auto эмулятор показал ANR в HardwareRenderer.syncAndDrawFrame; повторный прогон ведётся с SwiftShader. Этот факт сохранён в журнале аудита, а не скрыт.

Исходные требования и первоначальная приёмка сохранены в `reference/` и `validation/ACCEPTANCE.md`; для версии 1.1 актуален более новый отчёт `validation/redesign/RESULTS.md`.


### Weekly review and project files

Home and More link to Weekly review: switch between calendar weeks, view completions by local day, project contributions, completed work and unfinished tasks due that week. A confirmed reschedule moves only unfinished tasks to a chosen date, retaining time, project, priority and recurrence identity. Week start follows Settings. Counts reflect current task records and actual completion timestamps.

Project details link to Project files. Add multiple documents/photos through Android’s document picker, view photo thumbnails, open files with installed apps, share through Android’s chooser or remove a copy after confirmation. Files are copied into private app storage (50 MB per file) and remain usable when the source goes away. No broad storage permission or network access. Project deletion and workspace reset clean up attached copies; originals are never removed. The existing JSON backup exports workspace records, not attachment binaries; this is stated in the export and files screens. Attachment metadata uses an atomic private JSON index, with UUID-named binary files, without changing the Room schema.
